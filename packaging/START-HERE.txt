houseCARL-Amethyst {{VERSION}} — Linux x86_64
================================================

houseCARL-Amethyst gives Codex and Claude Code native, data-layer access
to a Skyrim Special Edition profile managed by Amethyst. It reads Amethyst
staging and filemap state; it does not require Mod Organizer 2 or a
Windows compatibility layer.

Install
-------

1. Extract the complete release archive.

2. In a terminal, enter the extracted housecarl-amethyst directory and run
   one of:

     ./housecarl-amethyst-install --codex
     ./housecarl-amethyst-install --claude
     ./housecarl-amethyst-install --both

   The installer verifies SHA256SUMS before changing anything. It installs
   the self-contained server under:

     ${XDG_DATA_HOME:-$HOME/.local/share}/housecarl-amethyst/server

   Persistent connection and safety state lives separately under:

     ${XDG_CONFIG_HOME:-$HOME/.config}/housecarl-amethyst

3. Fully restart the selected host.

4. In the extracted release directory, discover the active Amethyst Skyrim
   configuration and create its connection manifest:

     ./housecarl-amethyst-install --connect-amethyst

   If both native and Flatpak installations contain usable profiles, repeat
   with --amethyst-config and the absolute AmethystModManager config path.

5. Pass the printed manifest path to housecarl_set_amethyst_connection, then
   verify the live profile with housecarl_amethyst_status.

Updating and rollback
---------------------

Quit Codex and Claude Code, extract the newer release, and run the same
install command. The prior server remains available as a one-step rollback:

  ./housecarl-amethyst-install --rollback --both

The target flag selects the host prompt consistently; rollback only swaps
the shared server and does not change either host configuration.

Uninstall
---------

  ./housecarl-amethyst-install --uninstall --both

Uninstall removes the shared server, rollback copy, installed skills, and
houseCARL MCP registrations. It deliberately preserves XDG configuration,
including the saved Amethyst connection and pending-redeployment state.

Requirements
------------

- Linux x86_64.
- Amethyst Mod Manager with a Skyrim Special Edition profile.
- Hardlink deployment is the verified v1 target.
- Codex, Claude Code, or both.

The server and installer are self-contained. System .NET is not required.
External Windows tools such as PapyrusCompiler and BSArch remain deferred;
native record, archive-reading, PEX-decompilation, NIF, and asset features
do not require Proton.
