# Linux preview 2.1.5 release checks, 17 November 2026

Version 2.1.5 packages the plugin-activation fix from [PR #26](https://github.com/ni1by2/houseCARL-Amethyst/pull/26), merged through `11f066d9`. An ordinary plugin retained only in Amethyst's `loadorder.txt` remains inactive. Forced masters and installed Creation Club entries remain supported; explicitly active plugins with missing sources still refuse. Plugin-bound archive eligibility uses the same activation set, retaining explicit INI loading and Custom-over-Skyrim overrides. The [activation contract](../architecture/amethyst-plugin-activation.md) describes the behavior.

## Runtime verification

The original defect reproduced in isolated producer-generated snapshots: 17 of the first 22 regression cases failed against the unchanged reader. The final fix adds 36 activation/archive cases across schema 9/rules 13 and schema 10/rules 14, 15, 18 and 19. A genuine rules-19 producer generated the additional archive-contender fixture. The existing stdio connection/restart test now includes disabled and missing historical order entries.

Local validation passed 7,931 C# tests, with zero failures and one existing Windows-only skip, plus 34 Python tests. An equivalent assertion cleanup was rebuilt and all 36 activation cases passed again. [CI on the final reviewed runtime commit](https://github.com/ni1by2/houseCARL-Amethyst/actions/runs/44147410520) passed the full build, tests and package checks. Local execution used a disposable .NET 10 container with private HOME/XDG directories.

Independent review identified a missing Custom INI override in archive eligibility. The correction adds six cases for additions, per-key fallback, replacement and empty overrides. A further case preserves the existing warning when the base Skyrim INI is missing. Follow-up reviews found no remaining actionable issues. Refreshed Code Review Graph results and existing focused Graphify navigation were checked against source.

## Release verification

The release changes version metadata and documentation after the reviewed runtime fix. The local versioned archive passed notices, manifest and payload hashes, all four native contracts, MCP initialization reporting 2.1.5, and the expected 34-tool list. Required release CI repeats its build, tests and package checks against the versioned source before publication. The archive, SHA-256 file and standalone installer come from that source; the published tag and anonymous downloads are checked against the prepared assets after publication. Final hashes and download URLs are retained in the release notes and external handoff.

Independent release review checked the version metadata, installer actions, .NET 10 requirements and 60 documentation paths/anchors. It caught wording that incorrectly attributed the existing rules-19 reader to this patch release; that sentence was corrected. Review used scoped source inspection because the graph runner could not access its cache. Local builds and package execution were performed separately as recorded above.

Version 2.1.5 retains .NET 10, the existing installer, pinned native readers and Papyrus utilities. It also includes the [refresh lifecycle suite update](amethyst-refresh-lifecycle-2026-11-17.md), which tested Amethyst 2.6.4-beta.4 using published houseCARL 2.1.4. That earlier compatibility result is historical evidence; this release does not change production compatibility pins or claim support for unverified contracts. The headless API refactor remains deferred.

Installation/rollback and isolated Proton CachyOS checks from earlier releases remain historical evidence. They are not repeated for unchanged installer/runner code. No live profile, game, prefix, mods, deployment or host registration is changed for this release. Synthetic tests and package checks do not certify live deployment, the manager GUI or gameplay.
