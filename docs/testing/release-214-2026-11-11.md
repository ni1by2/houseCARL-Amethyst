# Linux preview 2.1.4 release checks, 11 November 2026

Version 2.1.4 packages the reviewed Amethyst compatibility update from [PR #23](https://github.com/ni1by2/houseCARL-Amethyst/pull/23), merged at `a8248f0bd816b5fed7e794dda8b9feab167ddd8d`. The release changes version metadata and user documentation. It retains .NET 10, the existing installer and pinned Papyrus utilities.

The [runtime verification](amethyst-runtime-compatibility-2026-11-10.md) records 7,895 passing C# tests, one existing Windows-only skip, 31 passing Python tests, independent review and four-reader package checks. [CI on the reviewed runtime source](https://github.com/ni1by2/houseCARL-Amethyst/actions/runs/42878345039) also passed. These checks were not repeated locally for documentation-only edits; release CI runs its required checks against the versioned source.

Amethyst 2.6.3/rules 18 uses the verified rules-15 reader. Amethyst 2.6.4-beta.1/rules 19 uses its matching fourth reader; its producer control and packaged runtime passed while older native readers failed the case-distinct archive fixture as expected. Exact provider selection, full NUL-containing archive keys, source/intent changes and transaction races are covered by the recorded tests. Unknown contracts still refuse.

The local versioned package passed notice checks, its manifest/payload hashes, native contract validation, MCP initialization, version 2.1.4 and the expected 34-tool list. Required release CI repeats the package check before publication. Release assets are the archive, its SHA-256 file and standalone installer, all from the same source. The published tag and anonymous downloads are checked against the prepared assets after publication; final hashes and URLs are retained in the release notes and external handoff.

The [compatibility test guide](../amethyst-compatibility-testing.md) now explains who can run the suite, the GitHub Actions steps, local runs against an extracted 2.1.4 package, the fixed historical workflow baseline and expected negative comparisons. The guide distinguishes maintainer compatibility testing from read-only verification of a user's own saved connection.

Installation/rollback and isolated Proton CachyOS checks from earlier releases remain historical evidence. They were not repeated here because the installer, pinned utilities and runner code are unchanged. No live profile, game, prefix, mods, deployment or host registration was changed for this release. These checks do not certify live deployment, the manager GUI or gameplay.
